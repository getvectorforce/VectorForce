# Taste

## Product & Feature Strategy

- Prefers concentrating effort on a single polished, high-impact feature over adding many small features — believes one well-executed "wow" capability has more impact than breadth. Confidence: 0.6

## Workflow

- Expects project work to be recorded as durable state in the real store (e.g. a committed checkpoint via the project's own CLI against the real DB), not just exercised in throwaway/temp-DB smoke tests. Confidence: 0.55
